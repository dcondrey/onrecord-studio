# Investigative source validation

Research now validates the draft before the independent editorial model pass and supplies exact failure locations to that editor. This uses the existing call budget. The final result is checked again locally before it is saved.

An unsupported finding, request, question, or meeting action is withheld individually. Other supported work remains available. If anything is withheld, the generated title and overview are replaced so a rejected claim cannot survive above the validated components. The dossier records the limitation and its investigation log records the failed component and reason. Quotes and interpretations are never silently fabricated to repair a result.

For Council actions, the quoted item and full meeting date must belong to the same official document and the same content version. They may occur in different excerpts. The item excerpt no longer needs to repeat the agenda cover heading. A label such as `Item 605: Riverbed grant extension` can be normalized to the source's literal `ITEM-605` only when the explicit number matches and the full date and original quotations validate. No title-based guess, different item number, unrelated agenda date, or reused URL with changed contents can satisfy the check.

SQL citations must reproduce an entire executed result row, preserving values and types. A fragment that happens to occur in the serialized results does not qualify. JSON spacing may differ.

Cross-record reconstruction is part of bounded autonomous research. At most two initially retrieved documents with masking clues trigger local comparisons. The original retained quotations become evidence; candidate identities or joined numeric fragments are passed separately as unverified research leads, with their limitations and next tests. Reconstructed values are never inserted into the source text, and this step makes no extra model calls.

Scheduled follow-up now includes the prior case's unresolved questions, next tests, requests, meeting actions, and their user-maintained states in its research fingerprint. An unchanged opening set of search snippets no longer blocks a new next test or a completed request's follow-through. Cosmetic report IDs, timestamps, and headlines do not trigger new work. Existing daily call limits, scheduling intervals, and failure backoff still apply.

## Regression coverage

- Supported findings and evidence-grounded follow-up survive an unrelated invented quotation or request source; rejected claims disappear from the overview.
- Agenda dates and items can use separate excerpts of one publication, but cannot be combined across different documents or different versions at one URL.
- An item number cannot match part of another number, a year, or a dollar amount.
- Source-only normalization cannot guess a different item number or meeting date.
- SQL citations reject altered values, changed JSON types, and incomplete rows.
- A changed next test or completed request allows a case continuation against unchanged initial snippets; cosmetic metadata does not.
- Reconstruction passes original fragments as evidence while keeping the assembled number exclusively in the explicitly unverified lead.

These checks establish source fidelity and narrow structural constraints. They do not prove that a model's interpretation follows logically from a quote, that a candidate identity is correct, or that a spending difference demonstrates wrongdoing. The independent critical review, displayed competing explanations, precise next tests, and human review remain necessary.
