# Investigation briefing

The default dashboard starts with findings from saved research dossiers. It features one discovery with a ready next action and a compact list of other discoveries across the latest investigations, preserving older work explicitly marked in progress. Completed and dismissed suggestions remain available in their original dossiers.

Each featured finding includes its interpretation, practical consequence, exact retained passages or query rows, direct source links, alternative explanations, available counter-evidence, the next test and a related records gap. Request matching checks both the actual subject and shared evidence, so two requests do not become interchangeable merely because they cite the same broad report. Selecting a request opens only that request with its draft ready to read, preserving its original saved action identity. Other requests remain available on demand. Publication review opens the review workspace for the selected report.

The reading order favors recorded next tests, related requests, counter-evidence and distinct original source snapshots, with one finding per topic first. It is a navigation aid, not a confidence score. Repeated query results do not multiply the underlying exports into independent sources. Supporting and opposing citations must match retained evidence before a finding is featured. Monetary strings and missing query values remain unchanged.

Dated actions require a real calendar date quoted in retained agenda evidence. Past dates are presented as outcome checks; future dates require verification of the latest agenda. A cited meeting date is never labeled a comment deadline or proof that a vote occurred.

Research failures remain visible. The archived homelessness dossier, for example, records six unsuccessful deeper reads and eight follow-up searches that returned no passages. The briefing exposes those limits and distinguishes editorial review from a recorded empirical evidence challenge. A failed search does not establish that the agency lacks a record. Technical attempt logs are available without becoming the primary reading experience.

An empty catalog, a failed catalog read, paused research, missing model access and an active research stage have distinct messages. If a selected dossier leaves the current catalog, its cached evidence is withdrawn rather than replaced by another report. An older durable case can check its original dossier through the casework workspace.

First-use blockers include a direct route to the relevant research settings. Missing credentials identify the selected provider's exact environment variable and the automatically read `~/.env` file. The required call budget is research passes plus three review/challenge calls, with one discovery call only for enabled collection and discovery through a cloud provider. A saved limit too low for any complete run is distinguished from a daily balance that resets at 00:00 UTC. Completion dates come from actual saved dossiers, including when an older installation recorded a failed attempt as finished.

Full dossiers, casework forms, maintenance controls, manual request tools and response analytics open on demand. The default page uses actual saved evidence and does not prefill examples or pretend that a research run is underway.

Validation covers the archived homelessness and Police finance dossiers, exact query values, opposing-evidence checks, meeting dates, targeted request navigation, publication-review routing and unavailable research states. Temporarily removing polling identity checks makes both stale-response tests fail; allowing a removed report's cached snapshot to remain makes the dossier-withdrawal test fail.

## Rendered review

A local browser harness rendered the real archived dossiers through a read-only mocked research-status bridge. This checks actual browser layout and navigation; it is not native application end-to-end validation. Chrome displayed the finding and its request action in the first desktop and mobile screens without horizontal overflow. Selecting another discovery changed the displayed evidence; the citywide cost finding opened its citywide reconciliation request instead of an unrelated request sharing the same source.
