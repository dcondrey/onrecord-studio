Verify a signed OnRecord Studio package

This page checks internal consistency only: that the package’s signed manifest bytes hash to the SHA-256 recorded in the file, that the Ed25519 signature over those bytes verifies against the public key carried in the same file, and that the human-readable manifest field matches the signed bytes. The signing key is self-managed by the installation that produced the package and is not externally attested, so a pass proves the bytes are unaltered since that installation signed them — it does not prove who signed, and it makes no claim inside the manifest true. Nothing is uploaded: this page has no network access.
