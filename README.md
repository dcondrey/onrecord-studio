### Onrecord Studio

<img align="left" width="96" alt="Onrecord Studio logo" src="onrecord-studio/assets/app-icon.svg">
A desktop investigation tool for journalists and lawyers working public-records releases. It ingests agency portals, catalogs, and local files, then surfaces statutory deadline violations, redaction and provenance findings, and cross-document patterns as claims traceable to evidence.
