<h1>Onrecord Studio</h1>

<p><strong>A desktop investigation tool for journalists and lawyers working public-records releases. It ingests agency portals, catalogs, and local files, then surfaces statutory deadline violations, redaction and provenance findings, and cross-document patterns as claims traceable to evidence.</strong></p>
